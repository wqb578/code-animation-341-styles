## 使用

保留本目录与根目录 `风格挑选.html` 的相对位置。直接用浏览器打开挑选器，选 X code-video；卡片播放 GIF，点击可放大并切换。GIF 不带音轨；只用于比较画风，不保证按其他主题生成时完全相同。

原有 193 张静帧和 341 个提示词文件保持原样，新增 31 个 GIF 后共有 224 个条目有预览。
